What gets built

New code, on the dashboard's existing setup

  • Two scheduled jobs on Vercel, set up like the hourly attendance one.
  • New database tables for sources, drafts, issues and photo links, added with the same migration process as today.
  • Newsletter pages, a photos section on meeting pages, and the home page card, built from the components the dashboard already uses.
  • Who can approve: a new rule naming the Brand and Marketing lead, President and VP, separate from today's top-level access, so the website lead can't approve.
  • Running cost: about $2 a month for Claude; Resend, Slack, GitHub and Drive are free at 60 members.
